# 🎲 LuduStar Pro — অনলাইন মাল্টিপ্লেয়ার গেমিং প্ল্যাটফর্ম (লুডু, দাবা, ক্যারাম)
### 🇧🇩 1v1 & Team Real Cash Matchmaking Platform with 5% Commission Escrow Engine

## 🌟 প্ল্যাটফর্মের মূল বৈশিষ্ট্যসমূহ (Core Features)

1. **গেমস (Multi-Game Architecture):**
   - 🎲 **লুডু (Ludo Pro):** ১ বনাম ১ (1v1) এবং ৪ জন প্লেয়ার (2v2 Team অথবা Free-for-all)। ছক্কায় গুটি খোলা, টানা ছক্কার লিমিট, অপর খেলোয়াড়ের গুটি কাটা (Capture), স্টার সেফ জোন, এবং হোম পৌঁছানোর রিয়েলটাইম নিয়ম।
   - ♟️ **দাবা (Daba / Chess):** 1v1 স্ট্যান্ডার্ড দাবা মুভ রুলস, পিস ক্যাপচার, চেকমেট, রিজাইন এবং টার্ন টাইমার।
   - 🎯 **ক্যারাম (Carrom Clash):** 1v1 স্ট্রাইকার পজিশনিং, এম অ্যাঙ্গেল ও পাওয়ার কন্ট্রোল, সাদা/কালো কয়েন পকেট এবং রেড কুইন পয়েন্টস।
   - 🚀 **ভবিষ্যতের গেম সম্প্রসারণ:** মডুলার `GameEngine` আর্কিটেকচার, যার মাধ্যমে ভবিষ্যতে খুব সহজেই ৮-বল পুল, তাস বা অন্যান্য গেম যুক্ত করা সম্ভব।

2. **এসক্রো ওয়ালেট ও ৫% প্ল্যাটফর্ম কমিশন ইঞ্জিন (Financial Logic):**
   - প্রতি ম্যাচে প্লেয়াররা নির্দিষ্ট এন্ট্রি ফি (যেমন: ৫০৳, ১০০৳, ২০০৳, ৫০০৳ ইত্যাদি) জমা করে ম্যাচে প্রবেশ করে।
   - ম্যাচ শুরু হওয়া মাত্রই ওয়ালেট থেকে টাকা এসক্রো পুলে লক হয়।
   - **জয়ের হিসাব:**
     $$\text{মোট পুল} = \text{স্টেক} \times \text{প্লেয়ার সংখ্যা}$$
     $$\text{প্ল্যাটফর্ম কমিশন (৫\%)} = \text{মোট পুল} \times 0.05$$
     $$\text{বিজয়ী খেলোয়াড়ের প্রাইজ} = \text{মোট পুল} - \text{কমিশন (৫\%)}$$
     *(উদাহরণ: ২ জন প্লেয়ার ১০০৳ করে খেললে মোট পুল ২০০৳। প্ল্যাটফর্ম ৫% অর্থাৎ ১০৳ কেটে রেখে বিজয়ীকে ১৯০৳ তাৎক্ষণিক প্রদান করবে।)*
   - ম্যাচ বাতিল হলে ১০০% এসক্রো রিফান্ড।
   - প্লেয়ার ৩ বার টার্ন মিস বা ডিসকানেক্ট টাইমআউট হলে অপোনেন্টকে অটোমেটিক জয়ী ঘোষণা করা হবে।

3. **ইউজার ফিচারস (User Features):**
   - রেজিস্টার, লগইন ও প্রোফাইল ড্যাশবোর্ড (নতুন সাইন আপে ৫০৳ ওয়েলকাম বোনাস)।
   - **ক্যাশিয়ার (Deposit & Withdraw):** বিকাশ (bKash), নগদ (Nagad), রকেট (Rocket) এর মাধ্যমে ডিপোজিট রিকোয়েস্ট ও উইথড্রয়াল সাবমিশন।
   - **ইনভাইট ও রেফারাল:** বন্ধুদের ইনভাইট লিংক শেয়ারিং (রেফারাল কোড কপি বা WhatsApp/Messenger এ সরাসরি পাঠানোর ব্যবস্থা)।
   - **ম্যাচ হিস্ট্রি ও স্ট্যাটস:** মোট খেলা, উইন রেট %, মোট আয়, অতীত সব ম্যাচের প্রতিপক্ষ, স্টেক এবং জয়-পরাজয়ের ফুল রেকর্ড।
   - কুইক ম্যাচমেকিং (অটো-ফাইন্ডার) অথবা ৬ ডিজিটের গোপন রুম কোড দিয়ে বন্ধুদের সাথে প্রাইভেট ম্যাচ।
   - ইন-গেম লাইভ চ্যাট এবং কুইক ইমোজি রিঅ্যাকশন (🔥, 👏, 😂, 😭, 🎯, 🚀)।

4. **অ্যাডমিন মাস্টার প্যানেল (Admin Master Panel):**
   - **ড্যাশবোর্ড:** মোট রাজস্ব (৫% কমিশন থেকে প্ল্যাটফর্মের লাভ), মোট গেম ভলিউম, মোট প্লেয়ার ও পেন্ডিং রিকোয়েস্টের সার্বক্ষণিক হিসাব।
   - **ডিপোজিট ম্যানেজার:** বিকাশ/নগদ এর প্রেরক নম্বর ও TrxID দেখে ১-ক্লিকে অ্যাপ্রুভ (অটোমেটিক ব্যালেন্স যোগ) বা রিজেক্ট।
   - **উইথড্রয়াল ম্যানেজার:** প্লেয়ারের ক্যাশআউট রিকোয়েস্ট দেখে পেআউট কনফার্ম বা রিজেক্ট ও রিফান্ড।
   - **ইউজার ম্যানেজার:** যেকোনো প্লেয়ারের অ্যাকাউন্ট সার্চ, ব্যান/আনব্যান ও ব্যালেন্স এডজাস্ট (বিবাদ নিষ্পত্তির জন্য)।
   - **সিস্টেম সেটিংস:** প্ল্যাটফর্ম কমিশন % (ডিফল্ট ৫%) কমানো/বাড়ানো, মিনিমাম ও ম্যাক্সিমাম বেট নির্ধারণ, টার্ন টাইমার পরিবর্তন এবং নির্দিষ্ট গেম অন/অফ টগল।

## 🚀 লোকাল মেশিনে যেভাবে চালাবেন (How to Run Locally)

সার্ভার এবং ফ্রন্টএন্ড ক্লায়েন্ট ইতোমধ্যে বিল্ড করা আছে।

### ১. সার্ভার চালু করতে:
```bash
cd D:\Ludu\server
node src/index.js
```
সার্ভারটি চালু হবে: `http://localhost:5000`

### ২. অ্যাডমিন প্যানেলে লগইন করবেন যেভাবে:
- ব্রাউজারে `http://localhost:5000` এ যান।
- "Log In" এ ক্লিক করুন।
- **ইমেইল:** `admin@ludu.com`
- **পাসওয়ার্ড:** `admin123456`
- লগইন করার পর উপরে বেগুনি রঙের **"Admin"** বাটন দৃশ্যমান হবে। সেখান থেকে সরাসরি অ্যাডমিন মাস্টার প্যানেল কন্ট্রোল করতে পারবেন।

## 🌐 লাইভ ডোমেইনে ডেপ্লয় করার গাইড (Live Domain Deployment)

### অপশন ১: Netlify-তে ফ্রন্টএন্ড ডেপ্লয় ও শেয়ারেবল লিংক (Shareable URL)
প্রজেক্টটি Netlify-র জন্য শতভাগ প্রস্তুত করা হয়েছে (`_redirects` এবং `netlify.toml` যুক্ত করা আছে)।
1. [app.netlify.com](https://app.netlify.com/drop) এ যান।
2. **`D:\Ludu\client\dist`** ফোল্ডারটি সরাসরি টেনে নিয়ে ড্রপ (Drag & Drop) করুন।
3. অথবা আপনার GitHub রিপোজিটরি Netlify-তে যুক্ত করলে:
   - **Base directory:** `client`
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
4. Netlify আপনাকে সাথে সাথে একটি ফ্রি শেয়ারেবল লাইভ লিংক দিয়ে দিবে (যেমন: `https://ludustar-pro.netlify.app`), যা যে কাউকে পাঠিয়ে মোবাইল ও ডেস্কটপে টেস্ট করাতে পারবেন!

### অপশন ২: Docker ও Docker Compose (ফুলস্ট্যাক VPS ডেপ্লয়)
আপনার VPS (যেমন: Ubuntu 22.04/24.04 এ):
```bash
git clone <your-repo>
cd Ludu
docker-compose up -d --build
```
এটি পোর্ট `5000`-এ অ্যাপটি ব্যাকগ্রাউন্ডে চালু করে দিবে।

### অপশন ২: Nginx ও PM2 দিয়ে ডেপ্লয়মেন্ট
১. **Node.js ও PM2 ইনস্টল করুন:**
```bash
npm install -g pm2
cd /var/www/ludu
npm run build
pm2 start server/src/index.js --name "ludustar"
```

২. **Nginx Reverse Proxy কনফিগারেশন (`/etc/nginx/sites-available/ludustar`):**
```nginx
server {
    server_name yourdomain.com www.yourdomain.com;

    location / {
        proxy_pass http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

৩. **ফ্রি SSL ইনস্টল করুন:**
```bash
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
```
